## [1.0.1] - 2025-04-14

### Added
- Enhanced documentation across all `.md` files for clarity and completeness.
- Updated `CONTRIBUTING.md` with clearer contribution guidelines.
- Improved `.gitignore` to exclude additional unnecessary files.
- Revised `SUMMARY.md` to provide a better overview of the documentation structure.
- Added new documentation files: `FAQ.md`, `remover.md`, `searcher.md`, and `updater.md`.

### Changed
- Updated `README.md` to include more detailed instructions and project information.
- Enhanced `FAQ.md` with additional questions and troubleshooting tips.

### Fixed
- Corrected minor typos and formatting issues in various documentation files.

## [1.0.0] - 2025-04-14

### Added
- Complete installation script (`install.sh`) for setting up the JMF Hosting Egg Manager.
- Setup script (`setup.sh`) to create necessary directories and clone repositories.
- Configuration file (`jmf.config`) for mapping game identifiers to egg paths.
- Documentation for commands and usage.
- Initial project structure and basic scripts.
- Basic README.md with project overview.

### Changed
- Enhanced logging in `logger.sh` to provide better output formatting.
- Updated command-line interface (`jmf-cli.sh`) to include new commands.

### Fixed
- Fixed bugs in the egg removal process in `remover.sh`.
- Corrected issues with the updater script (`updater.sh`) not pulling the latest changes.
